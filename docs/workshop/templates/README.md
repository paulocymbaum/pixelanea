# Workshop templates (E2-014)

Pre-built example projects live in [`../../examples/projects/`](../../examples/projects/). Copy or open them directly for **File → Open** testing.

| File | Use in class |
|------|----------------|
| `blank-starter.pixelanea` | Distribute as the starting canvas (32×32, 8 frames) |
| `happy-face.pixelanea` | Show a finished single-frame sprite |
| `walk-cycle.pixelanea` | Demo multi-frame animation after duplicate-frames lesson |

Regenerate all examples:

```bash
./scripts/create-example-projects.sh
```

Manual fallback (if you need a custom starter):

1. Launch Pixelanea and create a 32×32 blank project with 8 frames.
2. Save As `starter.pixelanea` in this folder.
3. Distribute copies; students rename on Save As.

See [teacher-guide.md](../teacher-guide.md) and [pilot-protocol.md](../pilot-protocol.md).
