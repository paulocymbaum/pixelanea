# Pixelanea workshop — facilitator one-pager

**45–60 min · local-first · no accounts**

## Before class (15 min)

1. Install `.deb` on lab machines — see [teacher-guide.md](./teacher-guide.md#install-pixelanea-lab-prep--5-steps).
2. Optional: `sudo apt install zenity` for native File Open/Save dialogs.
3. Copy template projects from [`templates/`](./templates/README.md) (or [`examples/projects/`](../../examples/projects/)):
   - `blank-starter.pixelanea` — distribute to every student
   - `happy-face.pixelanea` — finished sprite demo
   - `walk-cycle.pixelanea` — animation demo after duplicate-frames lesson
4. Print [student-handout](./student-handout.md) (one per pair) and [shortcuts](../shortcuts.md).

## Session at a glance

| Time | Do this |
|------|---------|
| 5 min | What is pixel art? Show a `.pixelanea` file on USB |
| 5 min | **Open existing** template vs **Start blank** — two front doors |
| 15 min | Guided draw: face or fruit on 16×16 or 32×32 |
| 10 min | Palette presets + lock |
| 10 min | Eraser ("Fix mistakes") + undo |
| 10 min | Optional: Duplicate to 8 frames → blink or bounce → Play |
| 5 min | **Save As** → confirm **All changes saved** → copy file to USB |

## Key UI phrases

| Say | UI label |
|-----|----------|
| "Fix mistakes" | Eraser |
| "Pick a color from your art" | Eyedropper |
| "Stay inside your color set" | Lock palette |
| "When it says All changes saved, you're good" | Status bar |

## If file picker fails

Students see a manual path field. Write a template on the board, e.g. `/home/student/Desktop/my-art.pixelanea`.
