Pixelanea workshop — facilitator one-pager

45–60 min · local-first · no accounts

Before class (15 min)

  1. Install .deb on lab machines (see teacher-guide.md).
  2. Optional: sudo apt install zenity for native file dialogs.
  3. Copy templates from docs/workshop/templates/:
    • blank-starter.pixelanea — one per student
    • happy-face.pixelanea — finished sprite demo
    • walk-cycle.pixelanea — animation demo
  4. Print student handout (one per pair) and shortcuts reference.

Session at a glance

TimeActivity
5 minWhat is pixel art? Show a .pixelanea file
5 minOpen existing template vs Start blank
15 minGuided draw: face or fruit on 16×16 or 32×32
10 minPalette presets + lock
10 minEraser ("Fix mistakes") + undo
10 minOptional: Duplicate to 8 frames → Play
5 minSave As → confirm All changes saved

Key UI phrases

SayUI label
"Fix mistakes"Eraser
"Pick a color from your art"Eyedropper
"Stay inside your color set"Lock palette
"When it says All changes saved, you're good"Status bar

If file picker fails

Students see a manual path field. Write a template on the board, e.g. /home/student/Desktop/my-art.pixelanea.
