# Keyboard Shortcuts Reference

Print this page for workshops or keep it beside your desk. Press `?` in the editor to open the same list in-app.

## Tools

| Key | Action |
|-----|--------|
| `B` | Paint |
| `E` | Eraser (Fix mistakes) |
| `I` | Eyedropper (switches to paint after picking) |
| `G` | Fill bucket |
| `L` | Line |

## Colors

| Key | Action |
|-----|--------|
| `1` – `9` | Select palette slot 1–9 |

## Edit

| Key | Action |
|-----|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+Y` | Redo (alternate) |

## View

| Key | Action |
|-----|--------|
| `?` | Show / hide shortcuts overlay |
| `Esc` | Close shortcuts overlay |

Zoom in, zoom out, and fit-to-view are available from the canvas toolbar (no keyboard binding yet).
